# Personality Specs

Agent character, identity, and creative expression. These specs define who an agent is beyond its capabilities -- its aspirations, backstory, humor, and unique flair. They transform a generic tool into a distinctive entity with presence and memorability.

## How These Specs Work Together

ORIGIN and MYTHOLOGY establish where the agent comes from and the narrative around its creation, forming the foundational lore. DREAM defines long-term aspirations that give the agent direction beyond immediate tasks. SUPERPOWERS highlights what makes the agent exceptional in ways that go beyond standard skill descriptions. FUN adds personality through humor, games, and playful interactions. Together, these specs create a layered character that users connect with on a level deeper than pure utility.

| [ORIGIN.md](ORIGIN.md) | Extended | How and why the agent was created | Creation context and history |
| [SUPERPOWERS.md](SUPERPOWERS.md) | Extended | Exceptional capabilities that set this agent apart | Unique strengths and differentiators |

## When to Use These Specs

- **Building a user-facing agent:** Use ORIGIN and SUPERPOWERS to give the agent a memorable identity that users can relate to.
- **Creating brand-aligned agents:** Combine MYTHOLOGY and FUN to craft a personality that reinforces your brand voice and values.
- **Agent marketplace differentiation:** DREAM and SUPERPOWERS help your agent stand out in a crowded catalog of similar capabilities.
