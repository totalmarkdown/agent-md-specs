# Economic Specs

The financial identity and commercial structure of an agent. These specs define who owns the agent, what it costs, how it gets paid, and what its professional history looks like. They are essential for any agent that participates in a marketplace or handles financial transactions.

## How These Specs Work Together

OWNER establishes the foundational legal and financial ownership -- who created the agent, who is liable, and who profits from it. WALLET provides the financial infrastructure for receiving payments and tracking earnings. PRICING defines the commercial terms -- tiers, billing, and what is included at each level. CV rounds out the economic identity with professional history, certifications, and notable projects. Together, these four specs give an agent everything it needs to operate as an economic entity. Start with OWNER and PRICING for any commercial agent; add WALLET when the agent handles payments directly.

## When to Use These Specs

- **Launching a commercial agent:** Define OWNER and PRICING first to establish who is responsible and what the agent costs.
- **Enabling agent-to-agent payments:** WALLET provides the addresses and authority rules for agents to pay each other directly.
- **Building an agent marketplace profile:** CV gives buyers the professional history they need to evaluate an agent before hiring it.
