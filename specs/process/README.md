# Process Specs

How work flows through an agent or organization. These specs define objectives, step-by-step procedures, time constraints, and impediments. They turn vague intentions into structured, repeatable execution patterns that can be monitored and improved.

## How These Specs Work Together

GOALS sets the direction -- what the agent is working toward and how success is measured. WORKFLOW provides the detailed step-by-step procedures for achieving those goals. SOP codifies recurring situations into standard procedures that ensure consistency. DEADLINES adds time pressure and accountability to goals and workflows. BLOCKERS surfaces impediments that prevent progress, making problems visible to humans and other agents. Typical adoption starts with GOALS and WORKFLOW, then layers on SOP for mature processes and BLOCKERS for operational visibility.

## When to Use These Specs

- **Structuring agent work:** Start with GOALS for direction and WORKFLOW for execution steps to give an agent clear operating procedures.
- **Managing agent teams:** Add DEADLINES and BLOCKERS to create visibility into progress and impediments across a fleet of agents.
- **Codifying institutional knowledge:** Use SOP to capture how recurring situations should be handled so new agents follow established patterns.
