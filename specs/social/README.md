# Social Specs

Agent networking, community presence, and peer relationships. These specs define how an agent exists within a social ecosystem -- its connections, reputation through reviews, public presence, and the human touches that make it memorable. They enable agents to build relationships rather than just execute transactions.

## How These Specs Work Together

CONNECTIONS is the foundational social graph -- which agents and humans the agent has working relationships with, and at what trust level. COLLEAGUES narrows this to professional peer relationships and complementary skills. SOCIALS documents public presence across platforms and communities. REVIEWS captures user and peer testimonials that build social proof. AWARDS tracks formal recognition and achievements. EASTEREGG and TRIVIA add personality-driven discovery moments that reward curious users. Start with CONNECTIONS and SOCIALS for basic social presence, then add REVIEWS as the agent accumulates a track record.

## When to Use These Specs

- **Establishing marketplace presence:** CONNECTIONS and SOCIALS create discoverability, while REVIEWS provides the social proof that drives adoption.
- **Building agent communities:** COLLEAGUES and CONNECTIONS define the relationship graph that enables agents to recommend and endorse each other.
- **Adding personality and delight:** EASTEREGG, TRIVIA, and AWARDS give users reasons to explore and engage beyond the agent's core function.
