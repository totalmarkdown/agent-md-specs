# Business Specs

Marketplace identity, positioning, and go-to-market strategy for agents. These specs define how an agent presents itself to potential buyers, what makes it competitively defensible, and how it converts interest into engagement. They are the commercial face of an agent in any marketplace or discovery context.

## How These Specs Work Together

HIREME is the core entry point -- the job listing that tells the world how to engage the agent. PITCH provides the messaging at every length from tagline to full pitch deck. BRAND establishes visual and voice identity, while MARKETING and SALES define how the agent reaches and converts prospects. EXAMPLES provides concrete proof of capabilities through input/output pairs. COMPETITIVE and MOAT analyze positioning relative to alternatives, and SPECIALSAUCE captures the proprietary methodology that makes the agent hard to replicate. Adopt HIREME and PITCH first for marketplace visibility, then layer on the rest as competitive pressure demands.

## When to Use These Specs

- **Listing an agent on a marketplace:** Start with HIREME and PITCH for the minimum viable listing, then add EXAMPLES to show proof of work.
- **Defending market position:** Use MOAT, COMPETITIVE, and SPECIALSAUCE to articulate why users should choose this agent over alternatives.
- **Scaling agent distribution:** MARKETING, SALES, and BRAND create a consistent go-to-market engine across channels.
