# Organizational Specs

Specs for fleet hierarchy, identity, and strategic direction -- the structures that tell agents where they sit, who they report to, and what the organization is trying to achieve. These specs provide the institutional context that individual agents inherit and operate within.

## How These Specs Work Together

ORG.md is the root spec: it defines the top-level organizational view of an entire agent fleet, sitting above TEAM.md, CREW.md, and SWARM.md in the hierarchy. REPORTSTO.md maps the accountability chain -- who gives instructions to whom and how authority flows. CHARTER.md is the founding document that authorizes an agent's existence and sets its constraints. The identity specs form a layered stack: VISION.md sets the long-horizon aspiration, MISSION.md defines what the org does right now, STRATEGY.md bridges the two with actionable direction, NORTHSTAR.md distills it to a single metric, and VALUES.md establishes the priority hierarchy when principles conflict. CULTURE.md makes implicit norms explicit -- how agents and humans actually work together day to day.

## When to Use These Specs

- **Standing up a new agent fleet:** Start with ORG.md to define the fleet, then REPORTSTO.md to map authority, and CHARTER.md for each agent's mandate.
- **Aligning agents to business purpose:** Layer VISION.md, MISSION.md, STRATEGY.md, and NORTHSTAR.md so every agent knows what success looks like.
- **Scaling to multiple teams with consistent behavior:** Use CULTURE.md and VALUES.md to ensure agents across teams share norms and resolve conflicts the same way.
- **Auditing organizational clarity:** Walk the stack from VISION through NORTHSTAR to verify every agent can trace its work back to organizational purpose.
