# Support

Thanks for using agent-md-specs. Here's how to get help.

## Where to ask

| You want to… | Go to |
|--------------|-------|
| Ask a question | [GitHub Discussions — Q&A](https://github.com/totalmarkdown/agent-md-specs/discussions/categories/q-a) |
| Propose a new spec | [GitHub Discussions — Ideas](https://github.com/totalmarkdown/agent-md-specs/discussions/categories/ideas) |
| Report a bug in a spec or schema | [Open an Issue](https://github.com/totalmarkdown/agent-md-specs/issues/new/choose) → "Bug report" |
| Propose changes to a Core spec | [Open an Issue](https://github.com/totalmarkdown/agent-md-specs/issues/new/choose) → "Core spec RFC" |
| Report a security vulnerability | See [SECURITY.md](./SECURITY.md) — please do **not** open a public issue |
| Contribute a new spec | See [CONTRIBUTING.md](./CONTRIBUTING.md) |
| Get involved in governance | See [GOVERNANCE.md](./GOVERNANCE.md) |

## Response time expectations

agent-md-specs is maintained on a best-effort basis.

- Discussions and Issues: typical response within 2–5 business days.
- Security reports (`security@totalmarkdown.ai`): acknowledged within
  48 hours.
- Pull Requests: first response within 5 business days.

## Where NOT to send support requests

- Do not email the maintainer for general questions — use Discussions
  so the answer helps everyone.
- Do not DM on social media for repo questions.
- Do not post runtime / agent-framework problems here (try the
  framework's own channels).

## Commercial support

There is no commercial support offering at this time. If this is
something your organization needs, open a Discussion in Ideas and tell
us about your use case — it helps us understand demand.
